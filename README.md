# СРС 3. Моделирование приготовления лакокрасочных материалов

Отчёт-сайт и Python-модель прогнозирования вязкости ЛКМ (линейная регрессия и случайный лес)
с сравнением традиционного и интеллектуального управления.

**Данные синтетические и модельные**: они не подтверждают эффективность системы в реальном производстве.

## Содержимое
- `index.html` — отчёт (сайт для GitHub Pages)
- `viscosity_model.py` — генерация данных, обучение, метрики, сравнение управления
- `data/paint_viscosity_synthetic.csv` — учебный набор данных

## Запуск модели
```bash
pip install -r requirements.txt
python viscosity_model.py
```
